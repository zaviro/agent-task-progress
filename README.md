# agent-task-progress

用于记录定时 Agent 任务的进展、运行状态与无法可靠塞入调度器提示词的长期任务规范。

## 定位

调度器/定时任务只负责：

- 何时运行；
- 指向哪个任务；
- 引用该任务的权威规范文件。

当任务所需的提示词、历史状态、轮换列表、决策标准或长期上下文超出调度器适合承载的范围时，将它们存放在本仓库，并让定时任务在每次运行时先读取这些文件。

因此本仓库是定时 Agent 任务的**持久外部记忆与任务规范仓库**，而不是业务代码仓库。

## 存储约定

每个任务必须在 `tasks/` 下拥有一个独立目录；不得把不同任务的状态文件混放在同一目录中。

目录名使用稳定、可读的任务标识，例如：

```text
tasks/
  daily-backup/
    prompt.md
    status.md
    history.jsonl
  dependency-audit/
    prompt.md
    status.md
    history.jsonl
```

- `prompt.md`：可选但推荐。任务的权威长期提示词/执行规范；当定时任务提示词不足以完整承载任务逻辑时必须使用，并由调度器提示词引用。
- `status.md`：该任务当前状态、最近一次运行结果与下一步。
- `history.jsonl`：按时间追加的运行记录，便于自动化读取、轮换采样和避免重复工作。
- 任务目录内可增加该任务专用的日志或产物，但不能存放其他任务的数据。

新建复杂任务时优先创建 `tasks/<task-id>/prompt.md`、`status.md` 与 `history.jsonl`；定时任务提示词保持简短，只要求读取 `prompt.md` 并执行其中规范。
